## 📖 Overview
Maintaining a healthy diet shouldn't feel like a chore. The **Smart Nutrition Tracker** is designed to reduce the friction of manual food entry. Built using React Native, the app utilizes an artificial intelligence vision model to analyze meal photos captured through your smartphone camera. It automatically identifies the food and estimates key nutritional metrics, helping you maintain a balanced diet with intelligent dietary insights.

## ✨ Key Features
*   📸 **Snap & Analyze:** Instantly identify food items from captured images using advanced AI vision models.
*   📊 **Macro Estimation:** Automatically calculates nutritional values including calories, carbohydrates, proteins, and fats.
*   📝 **Automated Logging:** Seamlessly logs meals and updates your daily nutrition summary in real-time.
*   💡 **Intelligent Insights:** Improves tracking accuracy and eliminates the tedious process of manual data entry.

## 🛠️ Tech Stack
*   **Frontend / Mobile Framework:** React Native
*   **Core Technology:** AI Vision Model for Image Recognition
