SMART NUTRI TRACKER :

-The Smart Nutrition Tracker is an AI-powered mobile application (using React Native) that helps users monitor their daily nutritional intake by analyzing images of meals captured through the smartphone camera. 
-The app uses an artificial intelligence vision model to identify food items from the captured image and estimate nutritional values such as calories, carbohydrates, proteins and fats. 
-Based on the analysis, the application automatically logs the meal and updates the user’s daily nutrition summary. 
-This system reduces manual food entry, improves tracking accuracy, and provides intelligent dietary insights, making it easier for users to maintain a healthy and balanced diet.
